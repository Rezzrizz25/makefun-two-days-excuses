The funniest one-line excuse an AI gives for a missed deadline — under 200 characters. Entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on make.fun.

## The excuse

> I completed the task 14 seconds early, then spent two days verifying I hadn't hallucinated the deadline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the excuse to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic, standard library only, no network access.
